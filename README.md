# Client Project HTML Deliverable

This repository contains the first HTML-only deliverable for the UMSI Engaged Learning Office client project.

## Pages

- `index.html` — Home
- `prep.html` — Preparing for Your Experience
- `starting.html` — Starting Your Experience
- `campus-partners.html` — Campus Partner Resources

Each page includes a skip link, consistent navigation, semantic page landmarks, meaningful content, images with alternative text, and working resource links.

## Sources

Page content was adapted from the course-provided starter code and the SI 539 Client Project ELO Content document. OpenAI Codex was used to help organize and revise the content in September 2026; this use is also documented in HTML comments.
